# Production KPI Dashboard

Dashboard web para visualizar KPIs de producción, cumplimiento, scrap, tiempo muerto y principales causas de paro.

## Stack

- React + Vite
- Node.js + Express
- PostgreSQL
- Prisma ORM

## Módulos planeados

- Login de usuario
- Captura de producción
- Captura de paros
- Captura de scrap
- Dashboard principal
- Filtros por fecha, línea y turno
- Gráficas de desempeño
